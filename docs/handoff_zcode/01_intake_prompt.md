# 提示词 1：接手并核验证据

将以下内容发给已打开本仓库的 Zcode：

---

你现在接手一个已结束实验、进入论文写作的 RAG 研究仓库。请完成写作准备，直接生成文件。

先阅读 `docs/handoff_zcode/README.md` 和 `docs/paper_v1/` 的五份材料。确认当前分支包含外部相关方法审计与最终 Phase 4 结果。记录当前 Git commit，不修改分支历史。

约束：禁止新增实验、训练、推理、评估、bootstrap、阈值选择；禁止改变冻结数字及协议；禁止为“完善论文”补造消融、引用、统计显著性或创新结论。

生成 `writing/review/intake_report.md`，包括：

1. 论文主问题及一句谨慎的研究主线，说明是候选表述。
2. 已有证据目录和文件存在性核验。
3. 主文建议采用的结果表来源，明确 dataset/split/seed/统计范围。
4. 支持、需限定、UNSUPPORTED 三类结论。
5. 缺少作者信息、参考文献元数据、写作理解的问题，使用 `[作者确认]` 或 `[待核实]`。
6. 是否能进入草稿写作；缺少服务器权重不构成写作阻塞。

同时生成 `writing/review/source_manifest.md`，记录当前 commit、主要来源路径和 SHA-256。只计算文件校验和，不重算实验指标。

重点回查 2Wiki Risk10 未达 10% 目标、Coverage Auxiliary 多 seed 无稳定收益、Router 是 adapted baseline、S2G/Stop/SURE 无同协议比较数字。若文档冲突，列出冲突及来源，不改原结果。

不需先问我常规写作偏好。以中文、学术组会与《电子与信息学报》初稿为默认用途。完成后用简短中文汇报接手情况；暂不运行实验或撰写整篇论文。
