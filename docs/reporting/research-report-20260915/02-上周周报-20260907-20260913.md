# 科研周报

周期：2026 年 9 月 7 日至 9 月 13 日

研究方向：证据充分性感知的自适应 RAG

## 一、本周主要工作

本周重点完成 HotpotQA 风险阈值实验的阶段收口，并推进第二数据集 2Wiki 的数据、检索及证据覆盖分析。本周报选择约一半重点成果展开，其余开发集对照将在后续周报中补充整理。

### 1. 整理控制器判别与消融结果

完成前期多种子实验的归纳。Query+Evidence score-aware 的 Macro F1 均值为 0.7971，优于直接拼接的 0.7523 和 Query+Stage 的 0.5773。覆盖辅助回归与 Hard Partial 采样没有稳定多种子增益。结果说明证据输入和组织方式有效，但仍需单独研究停止阈值与风险。

### 2. 完成 HotpotQA 风险与问答成本评估

将 Dev 按问题划分为校准集和策略选择集，冻结保守 Risk10 阈值后完成 Test 评价。主策略 FSR 为 8.45%；相比固定重检索，Answer F1 从 0.5108 变为 0.5104，平均累计 chunks 从 20.646 降为 9.380，Reranker 调用从 1.000 降为 0.207，组件测量汇总延迟从 587.79 ms 降为 347.67 ms。

配对问题级 bootstrap 显示 F1 差值置信区间为 [-0.0193, 0.0185]，满足预设 -0.02 非劣界限。FSR 区间为 [5.64%, 11.77%]，尚不能保证总体风险低于 10%。温度校准也未显示相对 raw 保守阈值的独立收益。此前已查看过该 Test，后续需依靠冻结的外部评价进一步检验。

### 3. 完成 2Wiki 数据与检索基础建设

整理官方 Train 167,454 题，划分 163,454 题 train_core 和各 2,000 题的 dev_calibration、dev_policy；官方有标签 Dev 12,576 题保留用于 Heldout 效果评价。共享 context 语料去重后形成 415,892 篇文档及 446,798 个句子对齐 chunks，supporting-fact 映射率为 100%。

完成索引和 Train/Dev 检索产物。BM25 八进程在百题检查中保持结果一致；批量 FAISS 出现排序差异，正式流程维持单 query 搜索。

### 4. 完成检索上限与阶段补救分析

在 2,000 题 dev_policy 上，Dense、累计 Hybrid 和最终 Rerank 的完整证据覆盖率为 32.20%、35.05% 和 36.60%。最终仍不完整的问题占 63.40%；Dense 不完整问题中仅 6.49% 能由后续阶段补齐，Hybrid 不完整问题中仅 2.39% 能被最终阶段补齐。

确认正式顺序 FSR 仅统计真实存在 Stop/Continue 动作的两个阶段，终止阶段证据缺失另计 Terminal Retrieval Failure。该诊断帮助区分控制器错误与冻结检索链的能力限制。

## 二、阶段认识

当前研究需要分别评价判别能力、停止策略风险和检索上限。HotpotQA 支持一定质量成本取舍，但不能表述为可靠风险保证；2Wiki 的证据覆盖不足则提示，继续检索未必总能补齐缺失事实。

## 四、可直接提交的简版

本周完成 HotpotQA 自适应检索的风险阈值与问答成本实验总结。冻结的保守 Risk10 策略在 Test 上 FSR 为 8.45%，Answer F1 为 0.5104，相比固定重检索，平均累计 chunks 减少约 54.6%，Reranker 调用减少 79.3%，组件测量汇总延迟减少约 40.9%。F1 满足预设非劣判据，但风险置信区间仍跨越 10%。同时完成 2Wiki 数据划分、语料去重、索引及检索一致性验证。开发集分析发现最终完整证据覆盖率仅为 36.60%，多数不完整问题无法由后续检索阶段补齐，需区分控制器误停与终止检索失败。下周将补充开发集基线比较，完成冻结与授权，并开展一次性 Heldout 评价。
